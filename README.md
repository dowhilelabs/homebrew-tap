# Homebrew Tap

Homebrew formulae for [Do While Labs](https://github.com/dowhilelabs).

## Install Papercut

```sh
brew install dowhilelabs/tap/papercut
```

This automatically adds the tap and installs
[Papercut](https://github.com/dowhilelabs/papercut).

## Install it-should

```sh
brew install dowhilelabs/tap/it-should
```

This automatically adds the tap and installs
[it-should](https://github.com/dowhilelabs/it-should).
